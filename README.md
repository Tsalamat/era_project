# Тест Магистратура

Бесплатная образовательная платформа для подготовки к КТА в магистратуру.

## Реализовано

- регистрация, вход и Bearer-токены;
- роли `STUDENT`, `TEACHER`, `ADMIN`;
- опубликованные тесты без раскрытия правильных ответов;
- попытки, автоматический подсчет баллов и объяснения;
- обычный учебный режим тестов с таймером, аналитикой и Word-отчетом;
- кабинет учителя: вопросы, четыре варианта, черновик, публикация и статистика;
- импорт вопросов из Word `.docx` одним файлом;
- Nuxt 3 интерфейс студента, учителя и администратора;
- PostgreSQL/Flyway, локальный H2-профиль и Docker Compose;
- Swagger UI: `/swagger-ui.html`.

Оплата, корзина, тарифы, платный доступ, внешний вход, режим записи/наблюдения, `payments` и `user_course_access` отсутствуют.

## Формат Word-файла для импорта вопросов

В кабинете учителя можно загрузить один `.docx` файл и добавить сразу все вопросы в тест. Каждый вопрос должен начинаться с номера, варианты должны идти строго `A-D`, правильный ответ указывается строкой `Ответ:`.

```text
1. Какой раздел проверяет критическое мышление?
A) Математическая грамотность
B) Оқу-аналитикалық сауаттылық
C) Профильный предмет
D) Иностранный язык
Ответ: B
Объяснение: Этот блок проверяет работу с текстом и выводами.

2. Какие инструменты помогают учиться по результатам теста?
A) Аналитика результата
B) Объяснение ошибок
C) Скачивание Word-отчета
D) Цвет темы сайта
Ответ: A,B,C
Объяснение: Несколько букв автоматически создают вопрос с несколькими ответами.
```

Можно использовать кириллические метки `А)`, `Б)`, `В)`, `Г)`. Если указан один ответ, вопрос сохраняется как `SINGLE_CHOICE`; если несколько через запятую, например `Ответ: A,C`, вопрос сохраняется как `MULTIPLE_CHOICE`.

## Docker

Весь проект запускается одной командой:

```bash
docker compose up --build
```

- frontend: `http://localhost:3000`
- backend: `http://localhost:8080`

## Локальный запуск

```bash
SERVER_PORT=8081 ./gradlew bootRun --args='--spring.profiles.active=local'
```

```bash
cd frontend
NUXT_API_BASE=http://localhost:8081/api \
NUXT_PUBLIC_API_BASE=http://localhost:8081/api \
npm run dev
```

Демо-аккаунты локального профиля:

- студент: `student@kta.kz` / `Student123!`
- учитель: `teacher@kta.kz` / `Teacher123!`
- админ: `admin@kta.kz` / `Admin123!`

## Проверка

```bash
./gradlew test
cd frontend && npm run typecheck && npm run build
```
