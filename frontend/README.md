# Тест Магистратура Frontend

Nuxt 3 интерфейс бесплатной платформы подготовки к КТА.

## Стек

- Nuxt 3, Vue 3, TypeScript;
- Pinia и cookie-сессия через Nuxt server endpoint;
- Tailwind CSS и Lucide icons;
- SSR, SEO metadata, `robots.txt` и `sitemap.xml`;
- рабочие сценарии студента и учителя.

## Запуск

```bash
npm install
NUXT_API_BASE=http://localhost:8081/api \
NUXT_PUBLIC_API_BASE=http://localhost:8081/api \
npm run dev
```

URL: `http://localhost:3000`
